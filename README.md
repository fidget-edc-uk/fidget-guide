# Fidget Toy Guide

An illustrated guide to fidget toys, built as a single static web page: every type with a live demo, the materials and finishes they're made from, tuning and play styles, and a finder.

## Run it

The guide is `app.html`; `index.html` is a tiny loader that always fetches the latest `app.html`, so the shared link never shows an old cached copy. Serve it with GitHub Pages:
Settings → Pages → Deploy from a branch → `main` / root.

Not affiliated with any maker.
